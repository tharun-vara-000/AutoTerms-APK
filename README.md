# AutoTerms

AutoTerms is an AI-powered Android application that analyzes Terms & Conditions, identifies privacy risks, generates summaries, and calculates risk scores.

## Features

- Terms & Conditions Analysis
- Privacy Risk Detection
- AI-powered Summarization
- Risk Score Generation

## APK Download

Download the APK from this repository and install it on an Android device.
